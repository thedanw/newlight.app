- **Decisions + WHY:**
  - `pagination.tsx`: `withProvider(Root,'root')` → `withRootProvider(Root)`. WHY: `withProvider` types props as `JsxHTMLProps`, colliding with Ark's `page: number` (TS2769). `withRootProvider` passes props through. Matches existing idiom (`dialog/menu/popover/drawer/tooltip/hover-card` all use it for Ark roots). No runtime change.
  - `dashboard.test.tsx`: `duplicateForm` mock typed as `FormWithFields`, not `Form`. WHY: it returns `Promise<FormWithFields>` (joins fields via `getFormById`); the old cast was TS2345. Imported from the forms barrel — no cross-module violation.
  - Z-index via recipe `&[data-toolbar-open="true"]` (zIndex 60) + `data-toolbar-open={toolbarOpen}` on the row — NOT inline style (violates findings #8) nor a separate `css()` class (scatters row styling, no merge-helper convention). Consistent with the existing D2 `data-open`/`data-visible` mechanism. Raw 60 chosen: just above overlay 50, below dropdown/sticky token territory (1000+). `position: relative` required (row is static).
  - Regression test asserts hook/class contract, NOT computed z-index. WHY: happy-dom has no stylesheet engine — `getComputedStyle().zIndex` returns 0 (first draft failed "expected 0 to be greater than 0"). Same reason the rowSelect tests assert recipe output.

### 6. HOW TO THINK ABOUT THIS PROJECT

1. **Pattern:** Two-layer Park UI — Ark headless logic + Panda recipe styling via `createStyleContext` slots; state flows through `data-*` attributes into recipe selectors. Root owns interaction (selection/pagination/massManage); pages own data/search. Keeps query logic in modules, interaction in shared components.
2. **Common mistake:** Duplicating ownership — a `search` prop on MainList (removed D5), internal `selectedKeys` in Root (removed #3), inline styles over recipes (#8), `withProvider` on Ark roots (breaks Ark prop types).
3. **Don't refactor:** The `data-*` + recipe-selector animation mechanism (deliberate D2, test-locked); the single-dashboard dedup (resolved, don't reintroduce a list page); per-surface coverage thresholds (intentionally scoped, not global).
