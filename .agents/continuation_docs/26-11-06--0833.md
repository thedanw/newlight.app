### 6. HOW TO THINK ABOUT THIS PROJECT

1. **Core architectural pattern:** Recipe-based styling with Panda CSS slots. All component styling goes through the mainList recipe, enabling consistent theming and reduced duplication.

2. **Most common mistake:** Attempting to add inline styles instead of using the recipe slots; forgetting to update all consumers when removing wrappers (like RowsComponent).

3. **Intentional non-refactoring:** The mainList recipe in `src/core/theme/recipes/main-list.ts` is the single source of truth for all slot styles; changes there cascade to all components. Do not refactor this unless adding new slot functionality.

### 7. DO NOT TOUCH LIST

- Do NOT refactor the mainList recipe unless adding new slot functionality
- Do NOT remove the `data-visible` attribute from MassManage - it's the mechanism for conditional rendering
- Preserve existing naming conventions for slot classNames
- Maintain the useMainListSelection hook structure - it's the source of selection truth
- Ask before introducing new frameworks or changing the Panda CSS recipe structure
